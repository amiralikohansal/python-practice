
# Number Guessing Game 🎯

A simple number guessing game built with Python.

## About the Project

The computer randomly selects a number between 0 and 100.

The player has 3 chances to guess the correct number.

After each guess, the game provides a hint:
- Try a smaller number.
- Try a larger number.
- Correct guess!

If the player uses all 3 chances, the game reveals the secret number.

## Features

- Random number generation
- Limited guessing attempts
- Input validation
- Error handling for invalid inputs
- Hints after each guess
- Win and lose messages

## Concepts Practiced

- Variables
- `random` module
- `while` loops
- Conditional statements
- User input
- Type conversion
- `try` and `except`
- Boolean variables

Python 3
